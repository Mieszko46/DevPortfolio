## :thinking: What's it about?
This mobile application is designed for runners. It allows users to create and manage plans, by specifying dates and routes for their running sessions. All data is securely stored in an online database hosted on the Heroku service, allowing seamless synchronization across multiple devices. The application includes robust security features such as HMAC-SHA1 for data integrity and JWT tokens for secure user authentication, ensuring that user data remains protected and private.

## 🖥️ Programming features
- **Android Studio** 
- **Kotlin** (client)
- **Ktor** (server)
- **MVVM** (pattern)
- **Heroku** 
- **Room** (local SQLite database manipulation)
